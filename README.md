# Controle-Inteligente-de-Bomba-de-Po-o-Artesiano
O projeto em questão está sendo desenvolvido mediante à necessidade do dia a dia de um sítio, no qual necessita de um controle inteligente e eficaz para realizar o acionamento da bomba do poço artesiano, permitindo mais aproveitamento diário da água e menos gastos com locomoção para ligar manualmente.
